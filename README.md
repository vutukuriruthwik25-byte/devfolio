# Ruthwik Vutukuri — DevFolio

A responsive personal developer portfolio for Ruthwik Vutukuri, built with semantic HTML and CSS. It introduces Ruthwik, highlights the Fieldnote Image Search and Fintech Risk Dashboard projects, and provides a working email contact link.

## Built with

- HTML5
- CSS custom properties, Flexbox, and CSS Grid
- Mobile-first responsive media queries

## Run locally

Open `index.html` in a browser.

## Live site

After enabling GitHub Pages for this repository, visit: https://vutukuriruthwik25-byte.github.io/devfolio/
